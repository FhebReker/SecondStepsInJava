# ICS4U - Computer Science (Java)
Coursework completed for Grade 12 Computer Science (ICS4U).

This repository contains seven major Java assignments that progressively develop skills in file processing, object-oriented programming, recursion, graphics programming, algorithm analysis, and advanced data structures.

### Technologies
- Java
- Object-Oriented Programming (OOP)
- File I/O
- Random Access Files
- Arrays and Array Processing
- Recursion
- Searching and Sorting Algorithms
- Binary Search Trees
- Data Structures
- Algorithm Analysis
- Modular Programming
- Java AWT
- HSA2 Graphics Library
